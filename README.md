# Reskill, Don't Replace

Individual project for MO-SS033 Contemporary World (A1105) by William Camua.

A one-page website on AI and automation in the Philippine BPO industry, arguing for industry-led reskilling backed by redeployment. Covers the issue, interview findings, the solutions considered, a pilot plan, SMART targets and references.

Open `index.html` in a browser, or view it through GitHub Pages.
